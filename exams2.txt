a x^2 + b x + c = 0

với a, b, c là các số thực.

Hàm cần xét đầy đủ mọi trường hợp có thể xảy ra, bao gồm cả trường hợp phương trình không còn là phương trình bậc hai.

Kết quả cần trả về
Trả về "No solution" nếu phương trình không có nghiệm

Trả về "Infinitely many solution" nếu phương trình có vô số nghiệm

Input: a = 1, b = -2, c = 1
Output: 1

Input: a = 0, b = 0, c = 0

def check_quadratic_equation(a, b, c):
    if a != 0:
        delta = b**2 - 4*a*c
        if delta < 0:
            return "No solution"
        elif delta == 0:
            return 1
        else:
            return 2
    else:
        if b != 0:
            return 1
        else:
            if c != 0:
                return "No solution"
            else:
                return "Infinitely many solution"

nums là danh sách các số nguyên dương đôi một phân biệt.

Hàm phải tìm số nguyên tố lớn nhất trong danh sách.

def is_prime(n):
    if n <= 1:
        return False
    for i in range (2, int(n**0.5)+1):
        if n % i == 0:
            return False
    return True

def largest_prime(nums):
    largest = -1
    for num in nums:
        if is_prime(num):
            if num > largest:
                largest = num
    return largest

Ví dụ:

thì kết quả phải là 27.
